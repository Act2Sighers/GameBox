# Round 1

## 受けた指示（要約）
- 画素数は粗め、画像は正方形
- キャラクターは全員「少女」のつもりで描く（風合いの指定）
- システム上は左右のみ。絵は真横ではなく斜め前向き
- 目にハイライト不要。怖く見えるなら縦線目・丸目などデフォルメ寄りに
- 頬の赤みは不要
- 鼻・口はほぼ不要。空いたスペースの分、目を少し下に寄せる

## キャラクター案
| # | 髪 | 服 |
|---|---|---|
| 1 | 黒髪ロングストレート | セーラー服（白・紺、赤スカーフ）、茶ローファー |

## フォーマット
全員右向き（左向きは左右反転）。輪郭線は塗りの外周に1px自動付与。

| | A | B | C |
|---|---|---|---|
| キャンバス | 16×16 | 24×24 | 32×32 |
| 頭の高さ / 体の高さ | 9 / 5 px | 14 / 8 px | 16 / 14 px |
| 頭身の目安 | 約1.6 | 約1.6 | 約1.9 |
| 目 | 1×2 縦線 | 2×3（下1段を明るく） | 2×4（下1段を明るく） |
| 目の間隔（内側） | 2px | 4px | 5px |
| 顔の向きの表現 | 顔を右寄せ、手前の頬を広く、奥の頬1px | 同左、奥の頬1px＋奥側の髪 | 同左 |
