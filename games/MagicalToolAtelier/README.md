# MagicalToolAtelier

魔法道具店を営む少女のゲーム。段階的に実装中。

- `index.html` — ゲーム本体（Artifactとして公開）
- `art/hero.py` — 主人公のドット絵（フォーマットB）。`python3 -B art/build.py` で `index.html` に反映し、`art/hero_sheet.png` を更新

## 実装済みの仕様

### 1回目
- 主人公：紺のとんがり帽子・紺のケープ・栗色の髪。直立＋歩き差分2枚
- 店内（13×12マス、1マス24px）：会計カウンター（L字、裏に回れる）と会計ボード、商品棚12（背の高い棚4＋陳列台8）、工房へのドア、玄関
- 自由移動（グリッドにスナップしない）＋上下左右の向き判定、向いた先の隣マスにグリッドスナップのカーソル
- 操作：左＝移動、中央＝状況で変わるボタン、右＝調べる。調べる中身は空実装

### 2回目
- 陳列台8台は個別のテーブル。「持つ」「置く」で配置変更（置き場所はグリッドスナップ）
- 背の高い棚は動かせない（内部的には同じ「設備」で、動かせるかどうかだけが違う）
- 動かせない障害物の周囲8マスには置けない。持っている間は赤い半透明で表示。陳列台どうしは隣接可

### 3回目
- 時間：右上の歯車 → オプション →「時間の流れ方」リアル／ゲーム
  - リアル：時刻は端末の時計に合わせる。閉じている間も進む（起動時に前回からの経過時間を把握）
  - ゲーム：30分で1日。布団に入っている間は30秒で1日。閉じている間は止まる
- ベッド（設備・障害物、1×2マス）：「布団に入る」で主人公が消えて布団が盛り上がる。「布団から出る」でベッドの左隣に出る。将来は工房側へ移す予定
- 窓の外（空・太陽／月・星・丘と家）と、店内全体の薄い色フィルター（早朝＝薄黄、夕方＝赤みのオレンジ、夜＝暗い青、境目のないグラデーション）
- セーブ：この端末（localStorage）に常に保存し、使えるときはアカウント（Artifactの `db`、本人だけが読める `data/users/<id>/save`）にも保存。起動時は新しい方を使う

### 4回目
- 部屋は「お店」と「工房」の2つ（どちらも13×12マス）。工房へのドアは廃止
  - お店の右上角・右下角から右へ通路。工房は左上角・左下角から左へ通路
  - 通路のマスに乗ると相手の部屋へ移り、同じ行の通路側（入ってきた側）から出てくる
- 工房：暗めの木の床、石積みの壁（干した薬草の束、瓶の並んだ棚）、お店と同じ位置の窓。玄関なし
- ベッドは工房の右上に移動
- 新しい設備
  - 乾燥棚（動かせる・1マス）×3：工房。陳列台と同じ仕組み
  - 宝箱（動かせる・1マス）：お店と工房に1個ずつ。後でインベントリ機能を持たせる予定
  - 大鍋（固定・2×2）：工房中央。煮え立つアニメーション（泡・湯気・下の熾火）。隣に固定の足場
- 持ち運びの制限：陳列台はお店専用。持ったまま通路に入ろうとすると壁のように止まる。乾燥棚・宝箱は部屋をまたいで運べる
- セーブデータは v2（部屋と、設備ごとの部屋を保存）。v1 のデータは商品棚12個の配置だけ引き継ぐ

### 5回目
- 動かせる設備を置ける場所のルールを変更
  - 障害物の隣にも置ける（壁・カウンター・他の設備が占めるマスと通路のマスには置けない）
  - ただし、置くと次の動線のどれかが通らなくなるマスには置けない（マス単位・上下左右の移動で判定）
    - お店：玄関の内側(6,10) → 右上の角(11,2)／右上の角 → 右下の角(11,10)／玄関の内側 → 全ての商品棚の隣のマス
    - 工房：左上の角(1,2) → 左下の角(1,10)
  - 陳列台を置く場合は、置いた陳列台自体にも玄関から行けること
  - 持ち上げた直後と、持ったまま部屋を移ったときに、置くと動線がふさがるマスを計算して赤く表示
  - 持ち上げる前から通っていなかった動線は判定に使わない（すでに行けない棚があっても置けなくはならない）

### 6回目
- アイテムの概念。アイテムは `{ type }` で、常に次のどこか1か所にある：持ち物枠／宝箱の枠／商品棚・乾燥棚の上（`furniture.item`）／部屋の床かカウンターの上（`ground`）
- 仮アイテム「猫のぬいぐるみ」（売れない・効果なし）。最初はカウンターの会計ボードの右隣(11,4)
- 持ち物枠：画面の上に5枠。入手時は左の空き枠から埋まる（自動で左詰めはしない）
  - 枠をタップ＝カーソルのマスに使う
    - 床（設備のない床マス）・カウンター → 置く。床やカウンターのアイテムは障害物にならない。カーソルを合わせると中央ボタン「拾う」
    - 商品棚（背の高い棚・陳列台）・乾燥棚 → 上に置く（1マス1個）。その設備にカーソルを合わせると中央ボタン「回収する」（アイテムが乗っている間は「持つ」にならない）
    - それ以外 → 枠が揺れるだけ
  - 満杯で入手しようとすると「鞄がいっぱいだ。鞄を整理しないと……」
- 右の「調べる」ボタンは必要なときだけ表示。宝箱に向くと「開く」
- 宝箱：6×5＝30枠。「開く」でウィンドウ。開いている間は持ち物枠と宝箱の間でドラッグ＆ドロップ（満杯の枠に落とすと入れ替え）。×か外側のタップで閉じる
- 床のアイテムがあるマスには設備を置けない
- キーボード：1〜5で持ち物枠を使う
- セーブデータ v3（持ち物、床のアイテム、設備の上のアイテム、宝箱の中身）。v1・v2 のデータは猫のぬいぐるみが初期位置から始まる

### 7回目
- 薬草取り：玄関のドアを調べると選択肢ウィンドウ（「薬草取りに出かける」「なんでもない」、外側タップでも閉じる。開いている間は操作不可）
  - 出かけると、ゲームが主人公を動かす：ドアの中央まで横に寄ってから下へ歩いて画面外へ → 現実時間で10秒（時間の流れ方の設定に関係なく一定）→ 下から歩いて戻る
  - 出かけている間は玄関の上に「あと◯秒」。戻ると持ち物枠に「薬草の入った袋」が1つ入る
  - 持ち物枠が満杯なら出かけられない（「鞄がいっぱいだ。鞄を整理しないと……」）
  - 半日（ゲーム内時刻の0〜12時／12〜24時）ごとに3回まで。超えると「（薬草が復活するのを待とう）」。選択肢に今の半日の残り回数を表示
  - 出かけている途中でゲームを閉じても、次に開いたときに続きから（外にいる時間は現実時間で数える）
- 新しいアイテム「薬草の入った袋」：スタックしない（1個で1枠）。麻袋から薬草がのぞく見た目
- セーブデータ v4（薬草取りの回数と、外出中の状態）

### 8回目
- 「マップ注視」と「持ち物注視」の2状態（起動時は必ずマップ注視）
  - 持ち物枠をタップ → 持ち物注視：マップ全体に半透明の黒、カーソルはタップした持ち物枠へ
  - マップをタップ／移動操作 → マップ注視：持ち物枠に半透明の黒、カーソルはマップへ
- 持ち物注視中、空でない枠では 右＝「調べる」（そのアイテムの説明）、中央＝「手に持つ」
- 手に持つ → マップ注視に戻り、主人公がアイテムを体の前に抱える（設備は頭上に掲げるので区別できる）。持ち物枠ではその枠がハイライト
  - 手に持っている間は 右＝「置く」（以前の「使う」と同じ置き方。置けない場所では枠が揺れる）、中央＝「しまう」
- 持ち物枠のタップでアイテムを直接置く操作は廃止（持ち物枠タップ → 手に持つ → 置く の3手）
- 設備を運んでいる間と布団の中では「手に持つ」は出ない（調べることはできる）
- キーボード：1〜5で持ち物注視、Escでマップ注視へ
- 手に持っている状態は保存しない（開き直すと手ぶら）

### 9回目
- 操作部品は「移動パッド」「Aボタン」「Bボタン」の3つに固定。位置と大きさは常に一定（A：右下、B：その左上）。長い文字はボタンを広げず文字を縮めて収める。使えないときのA/Bは点線の円
- 方針：よく使う操作はA。マップ→持ち物枠の向きの操作はB、持ち物枠→マップの向きの操作はA
- キーボード：WASD・十字キー＝移動、Space＝A、F＝B（1〜5＝持ち物枠を選ぶ、Esc＝マップ注視へ、は継続）
- ボタンの割り当て
  | 状況 | A | B |
  |---|---|---|
  | 動かせない設備を見ている | 調べる | 回収する（アイテムが乗っていれば）／布団に入る（ベッド） |
  | 動かせる設備を見ている | 調べる（宝箱は「開く」） | 回収する（アイテムが乗っていれば）／動かす |
  | 床・カウンターのアイテムを見ている | 調べる | 拾う |
  | 会計ボード・玄関のドアを見ている | 調べる | － |
  | 設備を運んでいる | 置く | － |
  | 布団の中 | 布団から出る | － |
  | 持ち物注視で空でない枠 | 持つ | － |
  | アイテムを手に持っている | 置く | しまう |
- 「拾う」は手に持った状態になる（しまうまで2手）。持ち物枠に空きが要る
- マップのカーソルは、位置が変わってから現実時間2.5秒で不透明度15%まで滑らかに薄くなる。位置が変わると即100%
- 持ち物注視中は、カーソルの枠のアイテム名と説明を常に表示（「[名前]」＋説明）。持ち物注視の「調べる」は廃止
- 宝箱ウィンドウでアイテムをタップすると、次の操作までウィンドウ下部に名前と説明
- 持ち物枠どうしのドラッグで入れ替え（宝箱を開いていなくても可）
- 主人公の当たり判定を足元の円に変更。角に引っかかると障害物のない側へ滑る。障害物の端に少しだけかかって正面からぶつかった場合も、横にずれて回り込む
