## ゲームの全体像
主人公（名前未定）が魔法道具屋を経営する。プレイヤーができること：
- 素材の調達（薬草取りなど）
- 設備を使った魔法道具の作成。ワンボタンではなく、工程ごとに設備を変え、各工程の作業を細かく追体験する
- 販売（陳列、接客、販売）
- 店内の設備の配置変え
- 販売で得た資金で新しい設備を購入
- 店を訪れる客を店員として雇い、任意の工程を任せる。給与、食事、性格などの特性に合った仕事選びといった管理が必要
- ゆくゆくは、新商品の開発以外は店員たちが自動でやってくれるようになる

## 作業画面
- 設備で作業するときは専用の「作業画面」に入る（参考：Artifact「仕上げ工房」。工程に合った道具を選び、工程ごとに小さな操作をする）
- 魔法道具は1回の作成で複数個できるものが多い。将来は「魔法の杖」「魔法の衣服」のように、1個しかできないが高価なものも出る
- 何らかの条件で作成に失敗すると、その工程の産物は価値のない「不良品」にまとまる

## 薬草
「薬草の入った袋」の中身は、実際には次の草の混ざりもの。袋ごとに各草の数がランダムで割合が違うので、袋どうしは同じアイテムとして扱えない（スタックしない理由）。

| 草 | 薬草 | 飼料 | 染料 | 特徴・見た目 |
|---|---|---|---|---|
| トトノイ草 | ◎標準 | × | | ハーブに似る |
| ピカラ草 | ○ | × | | 甘みを帯びる。葉が丸く、花が薄っすら光る |
| ミズモチ草 | ○ | ○ | | 水分が多い。葉や花びらが肉厚 |
| フツーノ草 | × | ◎標準 | | 葉が細長い |
| パサパサ草 | × | ○ | | 水分がほとんどない。表面がカサカサで少し茶色い |
| カラニガ草 | × | × | ◎黒 | 強い辛味と苦味。とても黒く、葉がイガイガ |

- 最初の工程は「作業台」での仕分け。見分けやすい見た目とは限らない
- 向いていない草で作る・混ざると質が下がる（作成はできる）
- カラニガ草が混ざったままポーションや餌を作ると必ず失敗する

### 作り方
- **ポーション**：仕分けた草 →「切り場」でナイフで刻む →「乾燥棚」に半日置く →「大鍋」で水と煮込む＝「草茶」→ 冷ます（置いておく／冷蔵庫）＝ポーション
  - ピカラ草：水をとても少なくするとポーションではなく「シロップ」
  - ミズモチ草：水を少なめにしないと質が下がる
- **練り餌**：仕分けた草 →「切り場」で刻む →「すり鉢」ですり潰す →「ボウル」で水と練る＝練り餌
  - ミズモチ草：水を少なめにしないと質が下がる。できた餌に「水気」タグ（水属性生物用を探す客が高く買う）
  - パサパサ草：水を多めにしないと質が下がる。できた餌に「乾燥」タグ（火属性生物用を探す客が高く買う）
- **インク**：染料向きの素材 →「すり鉢」ですり潰す →「ボウル」で少量の水と練る＝「着色剤」→「絞り機」で絞る＝「着色料」。カラニガ草などで作った真っ黒なものだけ名前が「インク」
- ポーション・シロップ・練り餌・インクには値段があり、質が低いほど下がる
